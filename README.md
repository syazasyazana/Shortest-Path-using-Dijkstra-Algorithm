# Shortest-Path-using-Dijkstra-Algorithm

"DETERMINATION OF THE SHORTEST PATH IN THE UMS MAIN CAMPUS
USING THE DIJKSTRA ALGORITHM"

This project applies Dijkstra’s algorithm, a graph-based optimization method, to determine the shortest walking paths between key locations in the University Malaysia Sabah (UMS) main campus. The campus is modeled as a weighted graph where buildings and landmarks are nodes, and the actual walking distances between them are edge weights. Implemented using MATLAB, the algorithm calculates optimal paths to improve campus navigation for students, staff, and visitors. The study aims to enhance accessibility, reduce travel time, and demonstrate the practical application of Dijkstra’s algorithm in a real-world environment.
